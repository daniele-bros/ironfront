# Iron Games

Iron Games is a free browser arcade by Daniele Bros at [irongames.win](https://irongames.win/).

| Entry point | Game |
|---|---|
| `minecraft.html` | **Ironcraft** — voxel building, exploration and survival |
| `ww2tanks.html` | **Iron Front** — top-down tank action |
| `command.html` | **Iron Battle** — real-time tactical strategy |

The games run directly in current desktop and mobile browsers with no account or purchase. Computer players use keyboard and mouse controls. Phones and tablets use on-screen touch controls; landscape orientation is recommended.

## Local development

```bash
npm install
python -m http.server 4173
```

Open `http://127.0.0.1:4173/`.

Run the site checks before publishing:

```bash
npm run build-activities
npm run verify-mobile
npm run verify-site
```

The activity pages are generated by `scripts/build-activity-pages.js`. Edit that source before rebuilding generated activity pages and `sitemap.xml`.

## Publishing

The production site is published from the `main` branch with GitHub Pages. The custom domain is stored in `CNAME`. Cloudflare provides DNS and the edge proxy for `irongames.win`.
